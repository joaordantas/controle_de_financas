# Trilha de Estudos

## Ordem recomendada
1. HTML basico
2. CSS basico
3. JavaScript basico
4. TypeScript basico
5. React basico
6. FastAPI basico
7. Consumo de API com `fetch`

## Como estudar
- Sempre estudar um conceito pequeno
- Sempre aplicar logo em seguida
- Sempre anotar com suas palavras
- Sempre revisar antes da proxima etapa

## Estudo da semana
### Bloco 1 - Fundamento
Escolha um tema:
- formularios HTML
- flexbox
- `useState`
- `fetch`
- rotas FastAPI

### Bloco 2 - Aplicacao
Use esse tema em uma parte do projeto:
- login
- cadastro
- categorias
- lista de transacoes

### Bloco 3 - Revisao
Responda por escrito:
- O que eu entendi?
- O que ainda me confunde?
- O que eu conseguiria refazer sozinho?

## Conceitos para revisar muitas vezes
- diferenca entre frontend e backend
- o que e uma API
- o que e um componente React
- o que e estado no React
- o que e uma rota no FastAPI
- o que e um service
- o que e um repository

## Mini exercicios sugeridos
- Criar um formulario simples em HTML
- Estilizar um card com CSS
- Fazer um array e renderizar lista em React
- Fazer um botao atualizar texto com `useState`
- Criar uma rota GET no FastAPI
- Fazer um `fetch` e mostrar o retorno na tela
