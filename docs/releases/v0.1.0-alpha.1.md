# Nivra v0.1.0-alpha.1 — Core Finance

Primeira versão pública de desenvolvimento da Nivra.

A Nivra é um controle financeiro em evolução, criado para reduzir o tempo necessário para organizar e compreender as próprias finanças. Esta release consolida o núcleo financeiro, a nova interface e a persistência PostgreSQL.

## Destaques

- frontend React e TypeScript;
- API FastAPI;
- dashboard financeiro;
- contas, saldos e conta principal;
- receitas e despesas;
- transferências entre contas, sem impacto em receitas ou despesas;
- categorias, histórico, busca e filtros;
- cartões, compras e ciclos de fatura;
- tema claro e escuro;
- layout responsivo;
- PostgreSQL persistente no Neon;
- migrations com Alembic.

## Infraestrutura

A aplicação é preparada para publicação integrada na Vercel: o bundle React atende a interface e o FastAPI expõe a API sob `/api`. O backend acessa o PostgreSQL no Neon usando SQLAlchemy Core e Psycopg. Credenciais permanecem em variáveis de ambiente e nunca são enviadas ao navegador.

O SQLite usado durante o desenvolvimento inicial deixou de ser o armazenamento oficial. Um importador dedicado permite auditar e transferir os dados legados sem modificar o arquivo original.

## Próximos passos

- autenticação segura validada pelo backend;
- parcelamentos e recorrências;
- orçamentos e metas;
- pagamentos parciais e ajustes de fatura;
- insights automáticos e área “Sua atenção”;
- Lumi, a assistente financeira da Nivra;
- notificações internas, resumos e WhatsApp.

## Status

Esta é uma versão **Alpha**. A autenticação e outras camadas de segurança ainda estão em evolução. A aplicação não é recomendada para armazenar informações financeiras críticas nesta etapa.

Lumi, insights, orçamentos, metas, recorrências e notificações pertencem ao roadmap e ainda não estão implementados.
