# Releases da Nivra

As notas desta pasta são preparadas antes da publicação de cada GitHub Release. A existência de um arquivo não significa que a tag ou a release já tenha sido publicada.

## Primeira release preparada

- Tag: `v0.1.0-alpha.1`
- Título: `Nivra v0.1.0-alpha.1 — Core Finance`
- Notas: [v0.1.0-alpha.1.md](v0.1.0-alpha.1.md)

## Publicação manual

1. valide que o commit desejado está na branch `main`;
2. abra **Releases** no GitHub e escolha **Draft a new release**;
3. crie a tag `v0.1.0-alpha.1` apontando para `main`;
4. use o título `Nivra v0.1.0-alpha.1 — Core Finance`;
5. copie o conteúdo das notas preparadas;
6. marque a opção **Set as a pre-release**;
7. revise os links e publique somente após a aprovação final.

A direção das versões futuras está no [roadmap público](../roadmap.md).
